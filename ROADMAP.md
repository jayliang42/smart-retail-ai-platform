# 24-Week Roadmap

This roadmap is milestone-driven. Weekly scope may change based on working code, tests, explanations, and review results.

> Engineering scaffold status (2026-08-11): the AI-assisted project already contains working
> evidence for many Week 1–20 milestones. This does **not** accelerate the learner baseline. Personal
> progression still starts with Week 1–4 explanation, debugging, and small independent changes,
> while the existing system supplies realistic code to study instead of disconnected exercises.

| Week | Engineering focus | Demonstrable outcome |
|---:|---|---|
| 1 | Python project structure, domain modeling, tests, Git | Validated retail event model with tests |
| 2 | SQL, PostgreSQL, relational modeling | Store/inventory/device schema and useful queries |
| 3 | HTTP, FastAPI, validation, errors | Event-ingestion and inventory APIs |
| 4 | Docker, configuration, integration tests | Deployable v0.1 local stack and English architecture walkthrough |
| 5 | ETL design and data quality | Repeatable event-cleaning pipeline |
| 6 | Queues, caching, idempotency | Reliable asynchronous ingestion path; code review |
| 7 | Regression/classification and validation | Baseline retail prediction model |
| 8 | Forecasting and anomaly detection | Deployable v0.2 forecasting/anomaly service and review |
| 9 | LLM APIs and prompt contracts | Structured Store Operations Copilot response |
| 10 | Tool calling and failure handling | Copilot reads inventory/device data; code review |
| 11 | Embeddings, semantic search, vector stores | Search over SOP and device documents |
| 12 | RAG, citations, context management | Deployable v0.3 grounded RAG flow and English walkthrough |
| 13 | Stateful AI workflows | Explicit multi-step operations workflow |
| 14 | Retry, timeout, recovery, idempotency | Fault-tolerant tool execution; code review |
| 15 | Human approval and permissions | Approval gate for high-risk actions |
| 16 | Multi-agent patterns and security | Deployable v0.4 controlled workflow; architecture walkthrough |
| 17 | Evaluation datasets and regression tests | Versioned copilot evaluation suite |
| 18 | Groundedness, hallucination, guardrails | Measured failure taxonomy and mitigations; review |
| 19 | Logging, tracing, latency, cost | Observable AI request lifecycle |
| 20 | Routing, fallback, batch/online inference | Deployable v0.5 production AI service and walkthrough |
| 21 | MQTT and device lifecycle | Simulated device-event ingestion |
| 22 | Edge processing and basic C++ interop | Small edge filter integrated with Python; review |
| 23 | CV/inference, serving, quantization basics | Benchmarked edge inference prototype |
| 24 | Hardening, CI/CD, cloud delivery | Deployable v1.0, portfolio README, final English defense |

## Review cadence

- Every week: one showable vertical feature.
- Every two weeks: code review and technical retrospective.
- Every four weeks: deployable release and English architecture explanation.
